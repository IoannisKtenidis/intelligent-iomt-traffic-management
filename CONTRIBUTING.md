# Contributing to intelligent-iomt-traffic-management

Thank you for your interest in contributing to this project!

## How to Contribute

1. **Fork the Repository**: Create your own copy of this project on GitHub.
2. **Clone the Fork**: Clone the project locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/intelligent-iomt-traffic-management.git
   cd intelligent-iomt-traffic-management
   ```
3. **Set Up the Environment**:
   - Create a virtual environment:
     ```bash
     python -m venv .venv
     source .venv/bin/activate  # On Windows: .venv\Scripts\activate
     ```
   - Install dependencies:
     ```bash
     pip install -r requirements.txt
     ```
4. **Create a Branch**: Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
5. **Run Tests**: Make sure all unit tests work by running:
   ```bash
   python -m unittest discover -s tests
   ```
6. **Submit a Pull Request**: Commit your changes, push to your fork, and submit a pull request describing the changes you made.
